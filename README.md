# Earth MIDI

**The planet as a live instrument.** Live earthquakes, solar wind, geomagnetic storms, tides, ocean swell, the ISS orbit and more, each run through the same rule every time and played as sound and MIDI in your browser. Same reading, same note.

Live at **https://earthmidi.com** · apps for iPhone, iPad, Mac and Apple TV in `apps/apple`.

**No active AI.** AI helped design and build Earth MIDI, including the rules that turn data into sound. No AI runs while you listen: every note comes from a published sensor reading.
