# Earth MIDI

**Earth MIDI by Colin Robinson.** The planet as a live instrument: live earthquakes, solar wind, geomagnetic storms, tides, ocean swell, the ISS orbit and more, mapped by fixed formulas to sound and MIDI. 0% AI in the sound.
